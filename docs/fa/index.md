# ZARVAN — جایی که جهان‌ها آغاز می‌شوند

**موتور بازی عامل‌محور و شبیه‌سازی‌محور، ساخته‌شده با Dart.**

ZARVAN یک موتور بازی دوبعدی (2D) است که هم برای انسان و هم برای عامل‌های هوش مصنوعی طراحی شده است. وضعیت جهان داده‌ی ساده‌ی JSON است که یک عامل می‌تواند بخواند و اصلاح کند، محتوا به‌صورت داده نوشته می‌شود، و منطق بازی که یک عامل می‌نویسد پشت یک جعبه‌ی ایمن اجرا می‌شود که نمی‌تواند شبیه‌سازی را خراب کند. Flutter فقط پوسته‌ی نمایش، ورودی و صدا برای Android، iOS و وب است.

## پنج ویژگی

| ویژگی | معنی |
|---|---|
| **عامل‌محور (Agent-Native)** | عامل‌ها کاربران درجه‌یک‌اند: وضعیت را به‌صورت JSON می‌خوانند و با patch، عملیات (CLI، MCP، REST) یا دستور (Order) تغییر می‌دهند. |
| **شبیه‌سازی‌محور (Simulation-First)** | شبیه‌سازی خودِ محصول است؛ کل بازی بدون صفحه‌نمایش هم اجرا می‌شود. |
| **داده‌محور (Data-Driven)** | وضعیت و محتوا داده‌ی قابل‌سریال‌سازی هستند. |
| **قطعی (Deterministic)** | تصادفی‌بودنِ دانه‌دار (seed) و گام زمانیِ ثابت؛ ورودی یکسان، جهانِ یکسان. |
| **توسعه‌پذیر (Extensible)** | داده‌ی تازه یعنی component، قانون تازه یعنی system، تصمیم تازه یعنی Behavior. |
