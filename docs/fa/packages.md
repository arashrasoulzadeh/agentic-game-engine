# بسته‌ها

| بسته | چه می‌دهد |
|---|---|
| `zarvan_core` | خود موتور: ECS، فیزیک پایه، `TileMap`، API عامل، قوانین نوبتی، قوانین idle و رجیستری عملیات. Dart خالص. |
| `zarvan_schema` | schemaهای دست‌نویس componentها برای CLI و Studio. |
| `zarvan_flutter` | پوسته‌ی Flutter: `Game`/`Scene`، sprite، دوربین، نور، ورودی، صدا، ذخیره/بارگذاری. |
| `zarvan_platformer` | گرانش، پرش، برخورد، AI گشت/دنبال‌کردن، انیمیشن. |
| `zarvan_strategy` | سیم‌کشیِ یک‌مرحله‌ای استراتژی نوبتی. |
| `zarvan_idle` | بازی‌های idle/افزایشی. |
| `zarvan_api` | سرور MCP و API ‏HTTP / JSON-RPC. |
| `zarvan_cli` | دستور `zarvan`: `create`، `upgrade`، `lint` و هر عملیات به‌صورت فرمان. |
| `zarvan_studio` | استودیوی بصری برای ویرایش سطح و محتوا. |

جزئیات و نمودار وابستگی (انگلیسی): [Packages](../packages.md)
