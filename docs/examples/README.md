# Examples

Focused, minimal, copy-pasteable recipes. **This repo does not check in
a runnable sample app** (`test_game/` is a real, gitignored local
sample used for manual verification only — see [CLAUDE.md](../../CLAUDE.md)
for why it's never committed). These snippets are illustrative, verified
against current source signatures under `packages/*/lib/src/`, but not
themselves a compilable project — drop them into a `Scene.populate` (or
wherever noted) in your own `game_agent create`-scaffolded project.
